# 🎮 Super Pong

Um jogo de ping pong simples desenvolvido na **Unity** como projeto de estudos, com o objetivo de explorar os fundamentos do desenvolvimento de jogos e colocar em prática conceitos da engine.

O **Super Pong** é inspirado na proposta clássica dos jogos de Pong, combinando uma jogabilidade direta com uma abordagem prática para aprendizado e experimentação.

## 🕹️ Sobre o projeto

O Super Pong faz parte dos projetos desenvolvidos pela **The Felix House**, um estúdio independente focado em desenvolvimento de jogos e software.

Este projeto tem como principal objetivo aprofundar os conhecimentos em desenvolvimento de jogos utilizando Unity, servindo como uma base para experimentar mecânicas, lógica de gameplay, interação com o jogador e outros recursos da engine.

## 🎯 Objetivos de aprendizado

- Explorar os fundamentos da Unity.
- Praticar a lógica de programação aplicada a jogos.
- Desenvolver mecânicas básicas de gameplay.
- Trabalhar com colisões e movimentação de objetos.
- Aprimorar conhecimentos em C# no contexto de desenvolvimento de jogos.

## 🛠️ Tecnologias utilizadas

- **Unity** — engine utilizada para o desenvolvimento do jogo.
- **C#** — linguagem de programação para a implementação da lógica do jogo.

## 🚀 Como executar o projeto

### Pré-requisitos

- [Unity Hub](https://unity.com/download)
- Unity Editor em uma versão compatível com o projeto.
- [Git](https://git-scm.com/) (opcional, para clonar o repositório).

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/victorfelixdev/SuperPong---Cheesper/
   ```

2. Abra o Unity Hub.
3. Selecione **Add** ou **Add project from disk** e escolha a pasta do projeto.
4. Abra o projeto utilizando a versão compatível do Unity Editor.
5. No editor, abra a cena principal do jogo e pressione **Play** para iniciar a execução.
